# Last Summer Promise

A browser-based visual novel in English (original language) with multi-language UI support.

## Features
- 2D anime-inspired visual style with multiple scenario backdrops.
- Story about **Yamada Isey (16)**, reunion with old playground friends, and summer romance.
- Branching choices with multiple endings.
- Beautiful heart-themed menu.
- Multi-language interface: English, Español, Português, 日本語.
- Built-in procedural background music toggle.

## Run locally
Open `index.html` directly, or use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
